# 🎨 Kiana.bio — Personal Portfolio

A personal portfolio website designed and developed for Kiana, showcasing her creative work, projects, and professional interests.

## 🔗 Live Demo

[Kiana.bio](https://kiana-bio.vercel.app/)

## ✨ Features

* Multi-page portfolio website
* Creative project showcase
* Custom page layouts and styling
* Interactive elements with JavaScript
* Custom fonts and visual assets
* Dedicated sections for different projects and creative works

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript

## 📁 Project Structure

```text
css/          # Stylesheets
font/         # Custom fonts
image/        # Images and visual assets
js/           # JavaScript files
pdf/          # PDF documents
index.html    # Main page
business.html
canfeex.html
drawing.html
payout.html
pottery.html
product-icon.html
wifi.html
```

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Kimia-msv/Kiana.bio.git
```

2. Open the project in VSCode
3. Run the project using Live Server
