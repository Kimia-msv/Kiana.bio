VANDAR DASHBOARD PAY OUT SERVICE

Overview

About project and Objective

About Project:

Vandar is a B2B financial platform for Payment and payout and managing money for Business.

In the Vandar dashboard, payout service allows users to transfer their wallet balance to their bank account.

Objective:
  • The most part of the dashboard that users deal with daily is Payout.
  • 15% of all problems were allocated is payout.
  • Resolving payout problems consumed a lot of the support team's time.

Problem solving

Solutions

After reviewing all the extracted issues, we reported a number of bugs to the technical team to be resolved, and we outlined the design-related issues in the following problem statement.

  • Reasons for the lack of settlement or delayed settlement:
    • UX & Functional problems

    The system does not inform users about the status of their transactions or when they are complete.

    Technical bug

    The system does not update the deposit time.

    Outcome

    UI Design

  • Notify users in transaction part

    • Notify users in transaction details and receipt, true estimated time and if we cant estimate it let user know that we show it soon.

    Outcome

    UI Design

  • Notify users in Dashboard notification

    • We need to send messages to users in the following parts:

    • If there are any errors or issues with the settlement request that require manual review
    • If there are any delays in the settlement process beyond the estimated deposit time
    • When the settlement has been successfully deposited into the user's account.

    Test

    Evaluate design

    The data that we extracted at the beginning of the project covered a two-month period, and out of 54 topics discussed, 41 were related to tracking the settlement status. After implementation, we reviewed this data again and found some interesting results.
